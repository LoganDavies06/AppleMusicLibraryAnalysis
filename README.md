# AppleMusicLibraryAnalysis
A tool for analysing Apple Music's library for those containing .m4a downloads (either cd rips, downloads or recordings)

Application is still in development
- Python code can be run without (any known) issues
- C++ SDL3 GUI is still in development

# To Run:
Execute build.sh in the terminal with this folder as the working directory

__This application is designed solely for use on MacOS__

# Required Libraries
- SDL3
- SDL3_ttf
- SDL3_image
